# 📚 Library Management System

A simple **Library Management System** developed using **Java** to manage books and library records efficiently. This project was created as a practical Java programming project to understand object-oriented programming and basic data management.

## 🚀 Features

* 📖 Add new books
* 🔍 Search for books
* 📋 Display available books
* ✏️ Update book details
* 🗑️ Delete books
* 📕 Issue books
* 📗 Return books
* 👤 Manage student/member records

## 🛠️ Technologies Used

* **Java**
* **Eclipse IDE**
* **Java Collection Framework**
* **Object-Oriented Programming (OOP)**

## 🧠 Concepts Used

This project provides practical experience with:

* Classes and Objects
* Encapsulation
* Methods and Constructors
* Conditional Statements
* Loops
* Exception Handling
* Java Collection Framework
* CRUD Operations

## ⚙️ How to Run

1. Clone or download this repository.
2. Open **Eclipse IDE**.
3. Import the project into Eclipse.
4. Make sure Java/JDK is configured.
5. Run the `Main.java` file.
6. Use the console menu to manage books and library records.

## 📌 Main Operations

```text
1. Add Book
2. Display Books
3. Search Book
4. Update Book
5. Delete Book
6. Issue Book
7. Return Book
8. Exit
```
